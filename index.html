Perguntas frequentes

Como recebo o acesso?

Logo após a confirmação do pagamento, você recebe o acesso por e-mail. No Pix, a confirmação costuma ser imediata.

A recepcionista consegue aplicar sozinha?

Sim. Os treinamentos foram feitos para a recepção assistir e aplicar no mesmo dia. A planilha fica com você, para acompanhar os resultados.

Serve para a minha especialidade?

Serve para clínicas que agendam consultas e avaliações particulares, como estética, odontologia, dermatologia e outras especialidades.

Funciona para clínicas que atendem convênio?

O método vale para qualquer agendamento, mas os maiores ganhos aparecem nos atendimentos particulares.

Quanto tempo dura o treinamento?

Menos de 3 horas no total. As aulas são curtas e diretas, pensadas para a rotina de uma recepção.

Por quanto tempo tenho acesso?

O acesso é vitalício. Você pode rever as aulas e usar os materiais sempre que precisar, inclusive para treinar novas recepcionistas.

Como funciona o webinário ao vivo?

Ele acontece toda semana, ao vivo, para o dono da clínica. Você escolhe a data depois da compra.

E se não fizer sentido para a minha clínica?

Ele só não faz sentido para clínicas que não querem aumentar os agendamentos. E, de qualquer forma, você tem 7 dias de garantia incondicional: se não fizer sentido, devolvemos 100% do valor.
